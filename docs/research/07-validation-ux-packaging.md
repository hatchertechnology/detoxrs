## Corrections Required

1. **f2's undo journal is not durable and is not XDG-anything.** It writes JSON to `os.TempDir()/f2/backups/<md5(cwd)>.json`. If Section 2's XDG recommendation is later used to imply "even f2 already does this," that implication is false — add an explicit note that f2's own undo storage is a cautionary example (temp-dir, hash-only filename, no state-dir usage) rather than a precedent to copy.
2. **cargo-dist has been rebranded "dist"** since Oct 2024; the crates.io package name `cargo-dist` is still the one that actually installs it because the bare `dist` crate name is squatted by an unrelated 2016 placeholder. Update Section 5 to name both the old and current brand and note the crates.io naming snag, since a reader would otherwise land on stale branding.
3. **figment is stale (last crates.io publish 2024-05-17)**, not "actively maintained" on par with `config-rs`. Either drop the "both actively maintained" framing in Section 4's table or explicitly flag figment as the higher-risk pick, noting the `figment2` community fork.
4. **detox's Homebrew formula is deprecated with a fixed sunset date (2027-07-28)** — the doc's "detox packaged in all major distros" framing (Section 5, "the bar to match/beat") should note that this bar is actively eroding, not static. This is new information the doc entirely missed, not merely "unverified."
5. **Terraform's stale-plan refusal is real but shouldn't be cited to the `apply`/`plan` doc pages** — those pages, read directly, don't state the drift-refusal behavior. Cite the actual "Saved plan is stale" error/mechanism (HashiCorp GitHub issues) instead, or find the specific docs page (if any) that documents it.
6. **Fedora packaging of detox is now confirmed** (Repology), so Section 5/Confidence-notes' "Fedora... not independently confirmed" should be upgraded from unverified to confirmed — this is a case where the doc was too conservative, not too confident.
